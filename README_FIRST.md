## Başlangıç

VS Code'da repo klasörünü açın. Codex'e `CODEX_PROMPTS.md` içindeki **PROMPT 0 — İlk analiz** metnini verin.

Codex planını sunduktan sonra onaylayıp **PROMPT 1 — Scaffold** ile ilerleyin.

## Bilinçli teknoloji seçimi

- Astro + TypeScript
- Tailwind CSS 4
- GSAP + ScrollTrigger
- React: yalnız gerçekten gerektiğinde
- Supabase: servis talep formu aşamasında
- Vercel: deploy

Ayrı Vite React SPA, Python/FastAPI veya Node/Express backend ilk sürüm için gerekli değildir.

## Tasarım hedefi

40–60 yaş kullanıcının zorlanmadan kullanabileceği; fakat kaliteli scroll storytelling, güçlü marka kimliği ve modern görsel işçilik sayesinde premium görünen bir teknik servis sitesi.
